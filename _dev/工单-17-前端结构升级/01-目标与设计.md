# 工单 17：前端结构升级

## 1. 工单目标

重排 cistella 桌面前端的工作区信息架构，将当前平铺工作区升级为“一级功能类别 + 二级具体功能”的两级导航，并在保持现有功能可用的前提下改善发现性、扩展性与日常操作效率。

本工单当前阶段为设计讨论与方案收口，先形成可执行文档，再进入前端施工。

## 2. 设计原则

- 一级类别表达用户意图，不表达实现模块。
- 二级入口表达可直接进入的具体工作区。
- 一级类别控制在 4—6 个，避免新的导航负担。
- 当前类别默认展开；当前二级入口有明确选中态。
- 命令面板、快捷键和直接路由继续保留，作为快速入口，不被两级导航替代。
- 不因为导航重排改变已有数据模型、Tauri command 合约或业务语义。
- 先完成现有工作区映射，再决定是否新增页面；不以分类为理由制造空页面。

## 3. A 层决策：信息架构

### 已拍板结构

采用“阅读 / 写作 / 管理 / 分析 / 工具”五个一级类别。写作当前作为可见的未来能力入口保留，但不虚构尚不存在的写作页面。

```text
阅读
  - 阅读工作区（reading）
  - 阅读会话（reading，会话功能入口）
  - 笔记与标注（notes）
  - 检索（search，作为阅读内嵌能力）

写作
  - 写作工作区（未来入口，暂不绑定现有 Workspace）

管理
  - 文献库（vault）
  - 文献资产（vault 内嵌功能）
  - 导入与导出（vault/source 相关操作）

分析
  - Source 分析（source）
  - 本地全文检索（search，作为独立分析入口）
  - 概览（vault/source 概览能力）

工具
  - 设置（settings）
  - 连接与诊断（vault/settings 相关操作）
```

### search 双归属规则

`search` 是唯一同时出现在两个一级类别中的能力：

- 在“阅读”下显示为“检索”，强调阅读过程中的上下文查找。
- 在“分析”下显示为“本地全文检索”，强调独立的数据分析/检索工作区。
- 两个入口暂时复用同一个 `Workspace` ID：`search`，不复制页面状态或后端能力。
- 导航模型允许一个 `Workspace` 被多个入口引用，但必须保留稳定的入口 key，避免选中态和命令面板冲突。

### 设计取舍

- “写作”显示为一级类别，但当前显示未来能力提示或禁用态，不创建空白页面。
- 一级类别允许折叠。
- 折叠状态暂不持久化；本状态属于 Studio/UI 层，不写入 Vault。后续如持久化，应使用 localStorage 或 Studio 配置，而不是工单数据文件。
- 现有 `Workspace` ID、快捷键和直接路由保持兼容。
## 4. 决策结果与 B 层待收口

A 层决策已于 2026-09-02 完成：

1. 一级类别采用“阅读 / 写作 / 管理 / 分析 / 工具”。
2. “写作”现在显示，作为未来关键能力的产品占位，但暂不创建虚假功能页面。
3. `search` 同时归属阅读和分析，分别使用“检索”和“本地全文检索”两个入口名。
4. 一级类别允许折叠。
5. 折叠状态暂不持久化；未来若持久化，属于 Studio 层，不属于 Vault 内容。

进入 B 层前需要确定：

- 写作占位的视觉状态：禁用、即将推出、还是展示说明卡。
- 一级类别展开/折叠按钮的具体交互和无障碍语义。
- search 双入口在命令面板中的展示方式。
- 一级类别与二级入口的图标、间距和响应式行为。
## 5. 交互草案

- 侧边栏顶部保留产品/库连接上下文。
- 一级类别为分组标题或可折叠按钮。
- 二级入口显示图标、名称和当前态。
- 当前路由进入时自动展开所属一级类别。
- 一级类别折叠不应隐藏当前页面的定位信息；当前类别至少保持展开。
- 命令面板显示二级入口，并在结果中显示所属类别。
- 小屏幕下一级类别展开后采用抽屉式或滚动式布局，不能导致内容区不可操作。

## 6. 兼容性约束

- 保持 `Workspace` 的现有 ID：`vault`、`reading`、`notes`、`search`、`source`、`settings`。
- 保持 Ctrl/Cmd+1—6 快捷键，必要时补充类别快捷键，但不在本工单第一阶段修改既有快捷键语义。
- 保持命令面板的打开/关闭行为。
- 不改变 Vault、Reading、Notes、Search、Source、Settings 页面内部业务逻辑。

## 7. 决策层

- A 层：一级类别数量、产品任务模型、是否引入写作类别。
- B 层：侧边栏交互、折叠持久化、命令面板分组呈现、响应式布局。
- C 层：组件拆分、类型定义、CSS module 与测试实现。

## 9. B 层收口结果

B 层已收口，形成可施工方案：

- 命令面板按一级类别分组展示二级入口，并保留快捷键与当前态提示。

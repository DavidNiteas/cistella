# 工单 22：前端工作区映射与回归

## 1. 工单目标

将导航、命令面板、路由和工作区状态映射到 `cistella-workspace` 的稳定业务契约，完成旧入口兼容、文案优化、可访问性和 bin_test 回归。

## 2. A/B/C 决策

### A 层：已确认

- 前端只消费业务 DTO/command，不直连 tree-space 路径、bucket 或 block。
- 导航按阅读、写作、管理、分析、工具等用户任务表达。
- 快捷键与说明仅在 hover/focus 提示中展示。

### B 层：施工裁定

- 使用 `workspace_contract` 作为前端与 Workspace 门面的首个稳定契约。
- 既有 Workspace ID 和路由继续兼容；不因底层迁移新增用户可见的底层路由。
- Sidebar 以 contract-aware aria label 消费协议，保持视觉导航紧凑。

### C 层：实现约束

- 新增 `useWorkspaceContract`，启动时请求 `workspace_contract`。
- TypeScript 维护 Workspace contract DTO 类型。
- Sidebar 接收 contract，不将 tree-space 内部名呈现给用户。
- 所有前端改动后运行 `pnpm build:bin-test`，同步 `bin_test/cistella-frontend/`。

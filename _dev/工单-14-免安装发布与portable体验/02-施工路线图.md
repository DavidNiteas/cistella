# 02. 施工路线图：免安装发布与 portable 体验

## 阶段门说明

本工单采用 M1/M2/M3 三阶段推进。四件套已完成；M1 尚未授权。

## M1：Portable 模式与数据边界

### M1 交付物

- `AppDirectories` 抽象（`cistella-core/src/app_dirs.rs`）。
- portable 模式检测逻辑：`is_portable_mode(exe_dir)`。
- 最近库列表 `recent_vaults.json` 读写（支持相对路径与绝对路径）。
- 应用配置 `config/app.json` 读写接口。
- Tauri 命令：`app_directories`、`recent_vaults`、`update_recent_vaults`、`is_portable_mode`。
- UI 首页/设置页显示当前模式与最近库列表。
- 迁移接口 Core 定义：`migrate_vaults_to_portable`、`migrate_vaults_to_installed`（M1 可只做接口与基础 Tauri 命令，UI 按钮可延后到 M2）。
- 新增集成测试 `crates/openalex-analysis-core/tests/工单14_m1_portable模式与数据边界.rs`。

### M1 明确不做

- 不做完整迁移向导 UI。
- 不做 Tauri 打包配置（ installer / portable zip 延后到 M2）。
- 不做单文件 exe、自动更新、数字签名。
- 不做跨平台 macOS/Linux portable 路径细节（M2 考虑）。
- 不改动 Vault 内部格式。

### M1 关闭标准

- `cargo fmt --check` 通过。
- `cargo test -p cistella-core --lib` 通过。
- 新增集成测试 `cargo test -p cistella-core --test '工单14_m1_*'` 通过。
- `cargo test -p cistella-core` 全绿。
- `cargo test -p cistella-desktop` 全绿。
- `cargo check -p cistella-desktop` 通过。
- `pnpm build` 通过。
- 代码审阅确认：portable 模式不泄漏数据到系统目录；安装模式不写入 exe 目录；最近库路径在 portable 模式下为相对路径。

### M1 验收命令（暂定）

```powershell
cargo fmt --check
cargo test -p cistella-core --lib
cargo test -p cistella-core --test '工单14_m1_*'
cargo test -p cistella-core
cargo test -p cistella-desktop
cargo check -p cistella-desktop
pnpm build
```

> 注：以上命令在 M1 施工阶段执行，作为施工完成的验证证据；设计阶段不得提前执行并以其结果作为设计依据。

## M2：打包产物与迁移向导

### M2 交付物（大纲）

- Tauri 打包配置：同时生成安装包（msi/nsis）与 portable zip。
- portable zip 包含：`cistella.exe`、`cistella-portable/` 空目录、`README-portable.txt`。
- 迁移向导 UI：允许用户选择 Vault 并迁移到 portable/installed 目录。
- 备份/恢复向导 Core 接口与 UI。
- 跨平台路径细节（macOS / Linux）评估与实现。

### M2 关闭标准（大纲）

- 能稳定生成两种打包产物。
- 迁移向导不丢失 Vault 数据。
- 不影响 M1 功能。

## M3：发布流程与可选增强

### M3 交付物（大纲）

- 版本号与产物命名规范。
- 自动更新检测接口（可选，可延后）。
- 离线安装包/单文件 exe 评估。
- 发布检查清单与回归测试。

### M3 关闭标准（大纲）

- 发布流程可重复。
- 回归测试覆盖 portable / installed 两种模式。
- 产物清单清晰。

## 共同约束

- portable 模式与安装模式的数据不得混用。
- 所有文件写入必须原子替换；失败时保持原数据完整。
- 最近库路径在 portable 模式下必须为相对路径。
- 新增依赖必须写入对应 crate 的 `Cargo.toml`，并在施工日志中登记。
- 测试必须覆盖 portable 检测、最近库读写、相对路径解析、模式隔离、迁移失败回滚。

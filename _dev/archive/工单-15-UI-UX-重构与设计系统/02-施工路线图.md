# 工单 15：施工路线图

## 1. 总体策略

采用「先让现有 UI 正确工作 → 再按工作区拆分与组件化 → 最后打磨体验与可访问性」的三阶段策略，避免一次性重写带来的回归风险。

## 2. 里程碑表

| 里程碑 | 内容/交付物 | 关闭标准 | 验收命令 | 依赖 |
|---|---|---|---|---|
| M1 | P0 基础修复：类名修复、Design Tokens、图标、基础组件、布局拆分、替换 window.confirm | 现有 UI 样式生效、无原生 confirm、基础组件可用、构建通过 | `pnpm build` + `cargo check -p cistella-desktop` + 六工作区手动走查 | 无 |
| M2 | P1 工作区拆分：按工作区拆页面与组件、DataTable 升级、空/错/加载态统一、响应式第一版 | App.tsx 行数 ≤ 200、各工作区为独立组件、表格支持排序分页、无 1180px 硬编码 | `pnpm build` + 六工作区功能回归 + 代码结构审查 | M1 |
| M3 | P2 体验打磨：Toast/全局状态、快捷键、Modal 焦点陷阱、暗色模式 tokens、可访问性审计 | 全局反馈统一、键盘可操作、暗色 tokens 生效、无 a11y 阻断问题 | `pnpm build` + 键盘全流程走查 + 暗色模式截图 + a11y 检查 | M2 |

## 3. 详细阶段划分

### M1：P0 基础修复与基础设施

**目标**：让现有界面先「看起来正确、操作可预期」，并建立后续重构的基础设施。

**批次 1.1：类名与样式修复（1-2 天）**
- [ ] 修复根节点 `className="app"` → `className="shell"`。
- [ ] 修复侧边栏 `className="sidebar"` → `className="side"`。
- [ ] 修复导航 active 态类名：`.selected` → `.nav.active`（或统一为 `.nav--active`）。
- [ ] 修复 Source Tab active 态类名：`.selected` → `.tabs button.active`。
- [ ] 修复 brand 结构，使其与 `.brand > span/b/small` 样式匹配（或调整 CSS）。
- [ ] 补全 Search、Notes、Import 预览等未定义类名的基础样式。
- [ ] 移除 `min-width: 1180px`，改为弹性最小宽度或基于 `clamp()` 的响应式约束。

**批次 1.2：建立 Design Tokens（1-2 天）**
- [ ] 新增 `src/styles/tokens.css`，定义颜色、间距、圆角、阴影、字体变量。
- [ ] 新增 `src/styles/global.css`，迁移基础 reset、滚动条、字体、焦点样式。
- [ ] 逐步将 `style.css` 硬编码值替换为 CSS 变量。
- [ ] 保留 `style.css` 作为过渡文件，最终目标是在 M2 完成后移除或大幅瘦身。

**批次 1.3：引入图标体系（1 天）**
- [ ] 安装 `lucide-react` 依赖。
- [ ] 创建 `src/components/ui/Icon/` 包装组件（统一尺寸 16/20/24）。
- [ ] 为侧边栏导航、收藏按钮、关键操作按钮替换字符图标（`★/☆` → Star/StarOff）。

**批次 1.4：基础 UI 组件（3-4 天）**
- [ ] `Button`：primary / secondary / ghost / danger / icon / loading。
- [ ] `Card`：统一卡片容器 + header。
- [ ] `PageHeader`：kicker + 标题 + 描述 + 操作区。
- [ ] `Dialog` / `ModalOverlay`：遮罩 + 卡片 + 关闭按钮。
- [ ] `ConfirmDialog` / `DangerDialog`：替换全部 `window.confirm`。
- [ ] `Toast` / `ToastContainer`：轻量通知栈。
- [ ] `Spinner` / `ProgressBar`：加载与进度。
- [ ] `EmptyState`：统一空状态。
- [ ] `Field` / `Select` / `Checkbox`：表单基础组件。

**批次 1.5：布局组件拆分（2-3 天）**
- [ ] `Shell`：根布局。
- [ ] `Sidebar`：导航 + Vault Selector + 底部状态。
- [ ] `StatusBar`：当前库路径、全局状态、版本。
- [ ] `MainHeader`：页面标题栏。
- [ ] `App.tsx` 仅保留 Shell + 路由逻辑。

**M1 关闭标准**：
1. `pnpm build` 通过。
2. `cargo check -p cistella-desktop` 通过。
3. 六个工作区可切换，导航 active 态正确。
4. 全部 4 处 `window.confirm` 替换为自定义 Dialog。
5. 无 `.app` / `.sidebar` / `.selected` 等已废弃类名残留。
6. 图标库已引入并应用于导航与关键操作。

### M3：P2 体验打磨与可访问性

**目标**：补齐全局反馈、快捷键、暗色模式、可访问性，达到「专业工作台」水准。

**批次 3.1：全局反馈层（2-3 天）**
- [ ] 用 Toast 栈替换散落在各处的 `setStatus(...)` 和 `literatureFeedback` 等内联反馈。
- [ ] 全局 Loading 遮罩用于长时间导入/重建索引。
- [ ] 后台任务进度在状态栏展示。

**批次 3.2：快捷键体系（2-3 天）**
- [ ] `Ctrl/Cmd+1-6` 切换工作区。
- [ ] `Ctrl/Cmd+K` 打开命令面板（切换工作区、打开最近库、搜索）。
- [ ] `Ctrl/Cmd+N` 新建文献条目。
- [ ] `Ctrl/Cmd+S` 保存笔记/文献。
- [ ] `Esc` 关闭弹窗、退出编辑器。
- [ ] 添加快捷键帮助面板。

**批次 3.3：Modal 与焦点管理（2 天）**
- [ ] 所有 Modal 焦点陷阱（focus trap）。
- [ ] Modal 打开时焦点落在主按钮或关闭按钮。
- [ ] `Esc` 关闭 Modal。
- [ ] 关闭后焦点回到触发元素。

**批次 3.4：暗色模式（2-3 天）**
- [ ] 完成 `data-theme="dark"` 与 tokens 暗色值。
- [ ] Settings 中增加主题切换（浅色/深色/跟随系统）。
- [ ] ECharts 图表在暗色下动态替换背景色与坐标轴颜色。

**批次 3.5：可访问性审计（2-3 天）**
- [ ] 所有按钮/输入有 `aria-label` 或可见标签。
- [ ] 导航使用 `aria-current="page"`。
- [ ] 表单标签与输入正确关联。
- [ ] 动态内容使用 `aria-live`。
- [ ] 配置 `eslint-plugin-jsx-a11y`。
- [ ] 键盘完成「连接库 → 导入文献 → 搜索 → 打开阅读」全流程。

**M3 关闭标准**：
1. `pnpm build` 与 `cargo check -p cistella-desktop` 通过。
2. Toast/全局状态/快捷键/Modal 焦点/暗色 tokens 全部生效。
3. 键盘可完成主任务流。
4. 暗色模式下六个工作区可读，ECharts 颜色正确。
5. `eslint-plugin-jsx-a11y` 配置完成，无阻断规则报错。

## 5. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 大文件拆分产生大量 diff | 审查困难、易引入回归 | 冻结其他 UI 功能；按文件/组件分 commits；每批次单独验收 |
| generation 守卫逻辑遗漏 | 过期响应污染当前库状态 | 拆 hooks 时原样保留 `captureVaultRequest` / `isCurrentVaultRequest` 模式，先不改逻辑 |
| Tauri API 版本差异 | 构建失败 | 拆分过程不升级依赖，保持当前 `@tauri-apps/api` 2.x 版本 |
| 响应式导致小屏体验差 | 用户分屏使用时不可用 | 优先保证 1024px 以上体验；800px 以下允许侧边栏折叠与表格横向滚动 |
| 暗色模式图表颜色异常 | 可视化不可读 | ECharts 主题随 `data-theme` 动态切换 |

## 6. 施工协议

- **先文档后实现**：任何实现偏离必须先更新本工单 `01-目标与设计.md`，并在 `03-开发状态.md` 登记，再动代码。
- **禁止双写**：状态细节只写本工单 `03-开发状态.md`；全局 `开发状态.md` 仅做导航索引。
- **偏离申请**：C 层实现细节偏离按默认规则裁定；触及 B 层设计或 A 层方向时升级经理。
- **分阶段闭合**：M1/M2/M3 各自独立验收，不累积到最后一刻。

- 2026-08-31：本干事完成 M3 实施：
  - 新增 `crates/openalex-analysis-core/src/import/remote/openalex_api.rs`，实现 `OpenAlexApiResolver`：`RemoteMetadataResolver` trait，支持 `Identifier::OpenAlexId` 与 `Identifier::DOI`，调用 `https://api.openalex.org/works/W<id>` 与 `https://api.openalex.org/works/doi%3A<encoded-doi>`，解析标题、作者、年份、类型、期刊/venue、外部标识符（DOI/PMID/PMCID/OpenAlex ID），缓存 namespace 为 `openalex_api`。
  - 新增 `crates/openalex-analysis-core/src/import/remote/semantic_scholar.rs`，实现 `SemanticScholarResolver`：`RemoteMetadataResolver` trait，支持 `Identifier::DOI` 与 `Identifier::PMID`，调用 `https://api.semanticscholar.org/graph/v1/paper/DOI:<doi>?fields=...` 与 `PMID:<pmid>?fields=...`，解析标题、作者、年份、类型、期刊、外部标识符（DOI/PMID/PMCID），缓存 namespace 为 `semantic_scholar`。
  - 扩展 `RemoteResolverRegistry`：
    - 默认注册 Crossref、PubMed、Semantic Scholar、OpenAlex API。
    - 新增 `from_app_dirs` / `with_app_config` 构造函数，在构建时按 `AppConfig.remote_resolvers_enabled` 过滤，缺失项默认启用。
    - 新增 `resolve_best`：按标识符类型顺序调用多个解析器（DOI → Crossref → Semantic Scholar → OpenAlex API；PMID → PubMed → Semantic Scholar → OpenAlex API；OpenAlex ID → OpenAlex API；PMCID → PubMed），按字段完整度合并结果；`source_name` 以 `" + "` 连接多个来源；`external_identifiers` 按 `namespace + 大小写不敏感 value` 去重。
    - 全部解析器失败时返回优先级最高错误：`NotFound > Malformed > Unavailable > Other`。
  - 扩展 `AppConfig`：新增 `remote_resolvers_enabled: BTreeMap<String, bool>`（`serde(default)`），并提供 `is_resolver_enabled(name)` 方法；旧配置缺失字段时视为全部启用。
  - Tauri 命令 `resolve_remote_metadata` 与 `import_by_identifier` 切换到 `resolve_best` 并经由 `from_app_dirs` 读取用户配置；新增 `clear_remote_metadata_cache(vault_path)` 命令删除 `<Vault>/cache/remote_metadata/`。
  - UI `App.tsx` 在 Reading 工作区「通过标识符导入」区域新增「清除在线解析缓存」按钮，调用 Tauri 命令并显示结果；补充中/英国际化字符串。
  - 新增集成测试 `crates/openalex-analysis-core/tests/工单13_m3_多解析器择优.rs`，使用本地 mock server 覆盖 OpenAlex ID/DOI 解析、Semantic Scholar DOI/PMID 解析、多解析器字段合并、禁用 Crossref 后的回退、全部失败错误、缓存清除后重新请求。
  - 新增 Cargo 依赖 `percent-encoding` 2.x（用于 OpenAlex/Semantic Scholar URL 编码）。
  - 为保持 `AppConfig` 向后兼容，给 `app_dirs.rs` 与 `tests/工单14_m1_portable模式与数据边界.rs` 中的显式 `AppConfig` 构造补充 `..Default::default()`，无逻辑变更。
  - 全部验收命令通过（结果见 `03-开发状态.md`）。
  - 设计偏离与说明：
    - 解析器启用/禁用未直接修改 `RemoteResolverRegistry::new()`，而是通过 `from_app_dirs` / `with_app_config` 在构建时读取；`new()` 保持默认全部启用，避免库测试出现隐式文件系统依赖。该方案满足 `02-施工路线图.md` §M3「解析器启用/禁用配置」与「构建时读取配置」的要求，无需偏离。
    - 择优错误优先级：`RemoteMetadataNotFound` > `RemoteMetadataMalformed` > `RemoteMetadataUnavailable` > 其他错误，在全部失败时返回优先级最高者。

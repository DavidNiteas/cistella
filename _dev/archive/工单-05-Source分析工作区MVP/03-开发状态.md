# 03. 开发状态：Source 分析工作区 MVP

## 当前阶段

已达成，已归档。

## 已完成

- Source 分析已作为独立一级工作区出现。
- 概览、表格、可视化、指标与导出五个任务面已建立。
- 当前工作区能显示来源适配器与 Vault 基础上下文，并支持刷新。
- 检索、排行与导出任务流已形成最小闭环。
- 最近查询、查询回放、当前筛选摘要、结果计数与排行计数已接入。
- 未连接 Vault 时有明确空态与连接入口，分析动作受库连接保护。

## 当前批次冻结范围

- MVP 只覆盖当前 Vault 内的 source 级数据。
- 检索采用字段筛选与名称关键词，不引入全文语义检索。
- 表格是主结果面；可视化是排行与比较辅助面；指标页只解释口径。
- CSV 是首选导出格式，现有 Excel 导出作为兼容能力保留。
- 最近查询是工作区本地偏好，不写入 Vault manifest。

## 当前施工项

- 已将已执行查询与正在编辑的筛选分离：摘要、结果计数、排行计数、图表和导出均绑定同一个已执行查询上下文。
- 已将查询、排行和概览刷新改为一次分析刷新：任一请求失败都会清空本轮分析结果，避免显示部分旧数据。
- 已统一无库、分析失败和已连接三种状态：无库时清空分析数据并禁用动作；失败时保留当前 Vault 上下文但清空分析结果并提供重试；连接或刷新成功后重新装载概览、排行和检索结果。
- 导出默认使用 CSV，并按当前已展示的结果/排行计数导出，避免导出上下文与页面计数不一致。
- 已确认 Source 视图仍只消费当前 Vault 的 source 级查询能力，不重新定义 Vault 边界。

## 关闭标准

- 用户可在单独工作区完成概览、筛选、排行、查看结果与导出。
- 导入后的 Vault 可直接进入 Source 分析，不需要重新解释上下文。
- 最近查询回放不会污染库 manifest。
- 本工单不侵入 Reading 与个人文献条目主线。

## 后续工单，不阻塞本工单

- 与文献条目、标签、收藏联动。
- 跨来源比较、保存分析视图与更丰富指标。
- 全文或语义检索。

# 02. 施工路线图：在线文献元数据补全与网络数据源适配

## 阶段门说明

本工单采用 M1/M2/M3 三阶段推进。四件套完成后需经经理阶段门授权方可进入 M1 施工。

## M1：Crossref DOI 解析

### M1 交付物

- `RemoteMetadataResolver` trait 与 `ResolveContext`（`cistella-core/src/import/remote/resolver.rs`）。
- 标识符规范化模块（`cistella-core/src/import/remote/identifier.rs`）。
- 缓存模块（`cistella-core/src/import/remote/cache.rs`）：
  - 缓存路径：`cache/remote_metadata/<namespace>/<sha256(identifier)>.json`。
  - 缓存结构：原始响应 + `SourceRecord` + 时间戳。
  - 过期判断与强制刷新。
- Crossref DOI 解析器（`cistella-core/src/import/remote/crossref.rs`）：
  - 使用 `reqwest` 调用 `https://api.crossref.org/works/<doi>`。
  - 解析 JSON 响应为 `SourceRecord`。
  - 错误处理：超时、无结果、格式错误。
- `RemoteResolverRegistry`：DOI → Crossref 分派。
- Core 错误变体：`RemoteMetadataUnavailable`、`RemoteMetadataNotFound`、`RemoteMetadataMalformed`。
- Tauri 命令：`resolve_remote_metadata`、`import_by_identifier`。
- UI：Reading 工作区「通过标识符导入」输入框与预览对话框。
- 集成测试：
  - `crates/openalex-analysis-core/tests/工单13_m1_crossref_doi解析.rs`
  - 覆盖：缓存命中、缓存过期、网络失败回退、响应解析、与 `LibraryImporter` 端到端。

### M1 明确不做

- 不做 PMID/PMCID/ISBN/OpenAlex ID 网络解析。
- 不做批量标识符导入。
- 不做引文网络、推荐、作者消歧。
- 不做付费或需要 API Key 的数据源。
- 不做 Source 分析工作区改造。

### M1 关闭标准

- `cargo fmt --check` 通过。
- `cargo test -p cistella-core --lib` 通过。
- 新增集成测试 `cargo test -p cistella-core --test '工单13_m1_*'` 通过。
- `cargo test -p cistella-core` 全绿。
- `cargo test -p cistella-desktop` 全绿。
- `cargo check -p cistella-desktop` 通过。
- `pnpm build` 通过。
- 至少一次真实 Crossref API 调用成功（可在本地手动验证，不进入 CI）。
- 不影响工单 12 导入功能。

## M2：PubMed / Europe PMC 适配

### M2 交付物

- PMID/PMCID 标识符规范化支持。
- PubMed/Europe PMC 解析器（`cistella-core/src/import/remote/pubmed.rs`）。
- `RemoteResolverRegistry` 扩展：PMID/PMCID → PubMed/Europe PMC 分派。
- UI 标识符类型自动检测（DOI / PMID / PMCID）。
- 集成测试 `crates/openalex-analysis-core/tests/工单13_m2_pubmed_pmcid解析.rs`。

### M2 关闭标准

- 同 M1 基础验收命令全绿。
- 新增 M2 集成测试通过。
- PMID/PMCID 解析端到端可用。
- 不影响 M1 功能。

## M3：OpenAlex API / Semantic Scholar 与择优策略

### M3 交付物

- OpenAlex ID 规范化与 OpenAlex API 解析器。
- Semantic Scholar 解析器（可选，按 DOI/PMID 查询）。
- 多解析器择优策略：当多个解析器返回结果时，按字段完整度/可信度合并。
- 解析器启用/禁用配置（用户设置）。
- 缓存手动清除按钮。
- 集成测试 `crates/openalex-analysis-core/tests/工单13_m3_多解析器择优.rs`。

### M3 关闭标准

- 同 M2 基础验收命令全绿。
- 新增 M3 集成测试通过。
- 多解析器择优与配置可用。
- 不影响 M1/M2 功能。
- 工单 13 归档。

## 共同约束

- 所有网络请求必须可超时、可重试、可禁用。
- 缓存写入必须原子替换。
- 解析结果必须通过 `SourceRecord` 进入现有 `LibraryImporter` 流程，不另建导入通道。
- 新增依赖必须写入对应 crate 的 `Cargo.toml`，并在施工日志中登记。
- 测试必须覆盖网络失败、缓存命中/失效、解析错误、端到端导入。

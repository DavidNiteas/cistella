## 设计输入与决议登记

本工单设计基于经理于 2026-08-31 的立项决策，A/B/C 三层决议已写入 `01-目标与设计.md`，核心摘要如下：

### A 层方向

- 工单 13 目标：在工单 12 基础上扩展在线文献元数据补全与网络数据源适配能力。
- 范围边界：M1 做 Crossref DOI 解析；M2 做 PubMed/Europe PMC；M3 做 OpenAlex API / Semantic Scholar 与多解析器择优。
- 核心原则：本地优先、网络数据作为补全来源、可禁用/可缓存/可错误回退。

### B 层设计

- 抽象：`RemoteMetadataResolver` trait + `RemoteResolverRegistry` 标识符分派。
- 缓存：`<Vault>/cache/remote_metadata/<namespace>/<sha256(identifier)>.json`，默认 30 天过期。
- 网络层：`reqwest` 异步 HTTP，默认 10 秒超时、1 次重试。
- 与工单 12 集成：解析结果转为 `SourceRecord`，复用 `LibraryImporter` 预览/提交。
- 错误策略：`RemoteMetadataUnavailable`、`RemoteMetadataNotFound`、`RemoteMetadataMalformed`。

### C 层默认

- 标识符规范化：DOI/PMID/PMCID/ISBN/OpenAlex ID。
- 解析器顺序：DOI → Crossref（M1）→ Semantic Scholar/OpenAlex API（M3）。
- Tauri 命令：`resolve_remote_metadata`、`import_by_identifier`。
- UI 入口：Reading 工作区「通过标识符导入」。
- 测试：本地 mock/录制响应，覆盖缓存、错误、端到端导入。

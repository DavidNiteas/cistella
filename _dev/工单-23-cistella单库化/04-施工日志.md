# 施工日志：cistella 单库化

## 2026-09-06：立项与设计细化

- 基于前端“库”概念混乱问题，复核 tree-space 与 cistella-workspace 的统一混合库能力。
- 用户确认产品方向：cistella 只有一个用户可见的库，文献、资产、笔记、阅读、来源数据与索引均作为该库内部内容存在。
- 建立工单 23 四件套与 `05-术语与页面映射.md`，确定 Vault 为 legacy/internal、Workspace 为技术聚合根、Library 为产品接口。

- 完成导航、命令面板、六个前端页面、关键 hooks、Tauri 命令、headless 兼容入口与 cistella-workspace 聚合底座盘点。

## 2026-09-06：M3 前端单库化

- 用户可见文案收敛为“库 / Library / 当前库”；移除普通界面中的 Vault Workspace、Reading Workspace、Source Analysis Workspace、current Vault 与输出库心智。
- 导航将根入口明确为“库管理 / Library”；命令面板和辅助导航不再把 Workspace 作为产品术语。
- 来源导入表达为选择来源目录并导入到当前库；资产明确区分库内副本与外部链接。

## 2026-09-06：M4 后端 façade

- 新前端全部调用 Library façade；旧 `vault_*` / `import_sources` 保持注册并转发，保证 legacy/headless 兼容。

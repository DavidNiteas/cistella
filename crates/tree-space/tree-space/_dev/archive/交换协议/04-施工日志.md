## E-2 权限 + 访问形式 施工 + 初审 + 返工 + 终审（2026-08-23）

**施工（flash）**：
- 新增 `src/exchange/ownership.rs`：所有权判定 + 写门——`require_owner(table, key)`（`Own` 放行；`Mapped`/缺席块 → `Err(OwnershipDenied)`）+ `ownership_denied` helper。
- 新增 `src/exchange/access.rs`：三种访问形式——`MappedView`（零拷贝映射 + 失效暴露 `invalid_state`/`mark_invalid`/`refresh`，`Source::Disk` 映射读 → `Err(MappingAmbiguous)`）、`OwnedSnapshot`（全量树+桶副本，所有权归读取者，手写 `PartialEq`/`Eq`）、`LazySnapshot`（先树后桶、按需复制）；`open_tree_mapped`/`read_tree_full`/`open_block_mapped`/`read_block_full`/`read_lazy` + 运行时表 dispatch `read_tree`/`read_block`（`read_block` 的 `AccessMode::Lazy` 防御分支 → `Err(PayloadMalformed)`）。
- 新增 `src/exchange/proxy.rs`：代理写语义——`ProxyRequest`（手写 `Eq`/`PartialEq`）、`RejectReason{NotOwner,InvalidPayload,ProxyRefused}`、`ProxyReceipt{Accepted,Rejected,TimedOut}`（回显 `request_id`）、`ProxyPolicy{Allow,Deny}`（`Default=Allow`）、`handle_proxy_request`、`ProxyClient`；IPC 传输封装 `publish_request`/`receive_request`/`publish_receipt`/`await_receipt`。
- `mod.rs`/`config.rs`/`lib.rs` 加法：`Holder::is_owner`/`is_mapped`/`source`；`RuntimeEntry::is_owner`；`RuntimeTable::set_tree_entry`/`mark_invalid`；`lib.rs` re-export（不含 `read_block`，见偏离 ①）。
- 新增 `tests/e_2_ownership_access.rs`（12 断言，含第 12 项 `Send + Sync` 编译期断言）+ `tests/e_2_proxy.rs`（8 断言）。

**初审（pro）**：1 处硬缺陷 + 2 建议。
- 硬缺陷：Unix `dup<0` 的 `from_raw_fd(-1)` UB（`libc::dup` 返回 -1 时 `from_raw_fd(-1)` 是未定义行为）。
- 建议 1：`read_block` 的 `AccessMode::Lazy` 防御分支错误码未明确（钉死 `PayloadMalformed`）。
- 建议 2：`take_bytes` 溢出（长度校验缺失）。
→ flash 返工修复：`dup<0` 拒绝；`read_block` Lazy 错误码钉死；`take_bytes` 长度校验。

**终审（主代理）**：四条命令独立复跑全绿（fmt --check；`-p tree-space -p tree-space-derive`；`rust-189 --all-targets`；`--workspace --all-targets`）；既有 P-IO-2..7 / v4 全套零回归；20 断言绿（12 + 8）；零新增第三方依赖；`MappedView`/`LazySnapshot` `Send + Sync`；既有公共 API 零破坏。

**6 项偏离裁定接受**（终审，全部接受）：
1. **① 根级不 re-export `read_block`**——与冻结的 `block::read_block` 重名，保留完整路径 `exchange::access::read_block`；
2. **② `OwnedSnapshot`/`ProxyRequest` 手写相等**——`TreeImage`/`Bucket` 无派生 `PartialEq`，手写 `PartialEq`/`Eq` 语义等价，避免为派生改动冻结类型；
3. **③ `await_receipt` 回显**——回执按 `request_id` 回显匹配；返工已修 Unix `dup<0` UB；
4. **④ `Source::Ipc` 不可字节序列化**——IPC 句柄不可稳定序列化，wire 只带 `Source` tag，句柄旁路传递；
5. **⑤ `publish_*` region 生命周期契约**——发布方须持有 `SharedRegion` 至接收方消费完（补 01 §3.2）；
6. **⑥ Send+Sync 第 12 断言**——`MappedView`/`LazySnapshot` 的 `Send + Sync` 编译期断言为 `e_2_ownership_access.rs` 第 12 项，由 §6.5 关闭标准覆盖。

**关闭标准核对**：四命令绿；既有零回归；20 断言绿；零新增第三方依赖；`Send + Sync`；零破坏。**E-2 关闭**。工作树改动（exchange/ + lib.rs + e_2 测试）待验收方固化。

## E-3 同步 施工 + 初审 + 终审（2026-08-23）

**施工（flash）**：
- 新增 `src/exchange/merge.rs`：同步范围 `SyncScope{FullTree,TreeFragment(Vec<XPath>),Blocks(Vec<RefId>)}` + merge 原语 `MergeOp{Overwrite,AddOnly,ModifyOnly,DeleteOnly,Combine(MergeFlags)}` / `MergeFlags{add,modify,delete}` / `MergeSpec{op,scope}` + `merge_image(dest,source,spec)`（纯函数：`Node` 命名/键控细粒度递归、位置型容器原子化、范围外不动）+ `reachable_refs(image,scope)`（可达块枚举，三种范围）。

- `mod.rs`/`lib.rs` 接线：`pub mod merge; pub mod sync;` + `lib.rs` re-export（`MergeFlags`/`MergeOp`/`MergeSpec`/`SyncScope`/`merge_image`/`reachable_refs`/`build_push_request`/`fetch_blocks`/`fetch_snapshot`/`pull`/`push`）。
- 新增 `tests/e_3_merge.rs`（13 断言）+ `tests/e_3_sync.rs`（12 断言）。

**初审（pro）**：结论通过、无返工。忠实度（对齐 01 §5 + 02 §7 签名）、正确性（merge 语义表 + 范围 + 可达枚举）、零破坏（仅 `exchange/` 加法 + `lib.rs` re-export）、测试充分性（13 + 12 = 25 断言）逐项通过。5 项偏离裁定建议（含偏离 ② 理由更正）：① `fetch_snapshot` FullTree 取源全桶；② `touched = shadow ∪ in_scope`（理由以初审更正为准）；③ `merge_image`/`reachable_refs` 不实际产 `Err`；④ pull 目的地须已加载库；⑤ pull 后旧块留孤儿、roundtrip 断言放宽。

**终审（主代理）**：四条命令独立复跑全绿（fmt --check；`-p tree-space -p tree-space-derive`；`rust-189 --all-targets`；`--workspace --all-targets`）；25 断言绿（13 + 12）；既有零回归；零新增第三方依赖；既有公共 API 零破坏。

**5 项偏离裁定接受**（终审，全部接受）：
1. **① `fetch_snapshot` FullTree 取源全桶（不裁剪）**——§7.4 `e_3_fetch_snapshot_full_tree` 断言 `bucket == 源全桶`；「按 `reachable_refs` 裁剪」措辞与之冲突，修正为 FullTree → 源全桶（不裁剪）、TreeFragment → 裁剪到范围内可达集；
2. **② `touched = shadow ∪ in_scope`**——**理由以初审更正为准**：「前缀在下、祖先 Node 需递归穿透」（in-scope 前缀的祖先 `Node` 必须一路穿透，故 `touched` = 穿透祖先（shadow）∪ in-scope 字段）；flash 原说理写反；
3. **③ `merge_image`/`reachable_refs` 不实际产 `Err`**——纯函数签名保留 `Result` 对齐错误语义面，但当前实现无错误路径，不引入虚假错误分支；
4. **④ pull 目的地须已加载库**——`dest.commit` 依赖已加载的 `LoadedState`，pull 前置要求 dest 已加载库；
5. **⑤ pull 后旧块留孤儿、roundtrip 断言放宽**——`commit` 只写不删（01 §6 桶块生命周期 = 树叶引用），dest 旧块留孤儿直到 GC，故「bucket 与 source 一致」不可达；放宽为「源可达块 ⊆ dest 桶（重开后）」。

**关闭标准核对**：四命令绿；既有零回归；25 断言绿；零新增第三方依赖；零破坏。**E-3 关闭**。工作树改动（merge.rs + sync.rs + mod.rs/lib.rs + e_3 测试）待验收方固化。

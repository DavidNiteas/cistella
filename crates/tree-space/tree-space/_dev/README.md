# tree-space `_dev`

本 crate 的 `_dev` 按全局**《工单模型》**组织（工单四件套、生命周期、聚合/子工单、工单引用），规范见 opencode 全局指令 `work-order-model.md`，此处不复述。环境与命令规范以仓库 `AGENTS.md` 为准。

## 入口导航

| 想看什么 | 去哪里 |
|---|---|
| 工单一览与状态（仓库级事实、演进史） | [`开发状态.md`](开发状态.md) |
| 需求/目标层的连贯路线（目标树 + 状态 + 工单引用） | [`设计路线.md`](设计路线.md) |

## 目录构成

```text
_dev/
├── README.md        # 本文：薄入口（指向全局规范 + 本层导航）
├── 设计路线.md       # 需求/目标路线（目标树，本层及以下）
├── 开发状态.md       # 薄索引：工单一览 + 仓库级事实 + 演进史
├── <工单目录>/       # 活跃工单（当前：树与桶管道）
├── suspended/       # 挂起工单（暂停施工，未闭合）
└── archive/         # 归档工单（已闭合；归档 ≠ 规范失效，被引用时照常引用）
```

- **活跃工单目录**：`_dev` 根下的工单目录（一次立项 = 一个工单，每工单含四件套）。
- **`suspended/`**：因外部原因暂停施工的工单（挂起 ≠ 闭合）。
- **`archive/`**：已闭合的工单整体移入（只读，仅允许勘误级小改）。
